# Changelog

The public changelog starts with the first open-source release of the
core. Releases are tagged `vYYYY.MM.N`; each entry lists the sync commit
from the private monorepo.

## v2026.08.0 — initial open-source release

- Core platform published under Apache-2.0: asset catalog, data
  contracts (ODPS), data quality, compliance, governance, scheduling,
  virtualization, connectors.
- Core-only runtime (`HUB_CORE_ONLY=1`) with GATE-29 boundary
  enforcement.
- Paid layer (semantic, marketplace, billing/BaaS, ML/AI, social)
  available via the hosted Meshant SaaS.
