## Overview

Each journey script maps to a user journey in [docs/USER_JOURNEYS.md](../../docs/USER_JOURNEYS.md). Scripts provide ordered steps with expected results, pass checkboxes, success criteria, and traceability links.

**Note**: Only 4 auth journeys (JOURNEY-AUTH-001–004) have dedicated scripts. The remaining 92 role-based journeys are covered via persona scripts (04-PERSONAS/).
