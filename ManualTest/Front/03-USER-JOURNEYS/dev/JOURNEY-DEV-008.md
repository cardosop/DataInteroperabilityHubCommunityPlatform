## What You Will Do

Browse plugins. Install plugin. Configure. Verify plugin works.

---

## Steps

| # | Action | What to Do | Expected Result | Pass |
|---|--------|------------|-----------------|------|
| 1 | Navigate to plugins | Go to **Developer** → **Plugins** or **Settings** → **Plugins**. | Plugins page | ☐ |
| 2 | Browse | View available plugins. | Plugins listed | ☐ |
| 3 | Install | Install a plugin. | Plugin installed | ☐ |
| 4 | Configure | Set plugin config. | Config saved | ☐ |
| 5 | Verify | Plugin functionality works. | Plugin active | ☐ |

---

## Success Criteria

- Plugins visible
- Install works
- Plugin functional
