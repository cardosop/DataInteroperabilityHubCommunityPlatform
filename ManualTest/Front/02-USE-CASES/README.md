## Overview

Each use case script maps to a use case in [docs/USE_CASES.md](../../docs/USE_CASES.md). Scripts provide step-by-step manual test instructions with expected results and pass checkboxes.

**Note**: Only 4 auth use cases (UC-AUTH-001–004) have dedicated scripts. The remaining ~105 use cases are covered via persona scripts (04-PERSONAS/), which reference journeys that implement multiple use cases.
