# Meshant Product Documentation

Meshant is a data interoperability hub that lets organisations publish,
govern, and monetise data products through a single platform. It combines
contract-driven ingestion, automated quality and compliance gates, a
semantic knowledge layer, and a built-in marketplace so that data
producers and consumers can exchange trusted, standards-compliant data
without point-to-point integrations.

The platform enforces tenant isolation, role-based access, and audit
trails from day one, and exposes every capability through a versioned
REST API, a Python SDK, a CLI, and webhooks.
