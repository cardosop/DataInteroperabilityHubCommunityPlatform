# Documentation Update Checklist

**Created**: 2026-01-26  
**Purpose**: Systematic checklist for updating documentation

## Pre-Update Checklist

### Information Gathering
- [ ] Identify all files that need updates
- [ ] Review related code changes
- [ ] Review related architecture changes
- [ ] Identify affected features
- [ ] Review user feedback (if applicable)
- [ ] Check for breaking changes

### Planning
- [ ] Determine update priority (Critical/High/Medium/Low)
- [ ] Assign documentation owner
- [ ] Set target completion date
- [ ] Identify reviewers
- [ ] Create update plan

### Accuracy
- [ ] All information is accurate and current
- [ ] Code examples work as described
- [ ] API endpoints are correct
- [ ] Configuration examples are valid
- [ ] Version numbers are correct
- [ ] Dependencies are up-to-date

### Completeness

### Consistency
- [ ] Terminology matches style guide
- [ ] Formatting follows templates
- [ ] Code style matches project standards
- [ ] Naming conventions are consistent
- [ ] Links use consistent format
- [ ] References follow style guide

### Clarity
- [ ] Language is clear and concise
- [ ] Technical terms are defined
- [ ] Examples are clear and useful
- [ ] Steps are in logical order
- [ ] Diagrams are clear (if applicable)
- [ ] Tables are well-formatted

## Technical Checklist

### Code Examples
- [ ] All code examples are tested
- [ ] Code examples use correct syntax
- [ ] Code examples include necessary imports
- [ ] Code examples show error handling (when appropriate)
- [ ] Expected output is shown
- [ ] Code examples are realistic and useful

### Links and References
- [ ] All internal links work
- [ ] All external links work
- [ ] Links use relative paths (for internal)
- [ ] Links are descriptive (not "click here")
- [ ] References section is complete
- [ ] Related documentation is linked

### Images and Diagrams
- [ ] Images are optimized for web
- [ ] Images have descriptive file names
- [ ] Images include alt text
- [ ] Diagrams are clear and readable
- [ ] Diagrams are stored in correct directory

### Formatting
- [ ] Markdown syntax is correct
- [ ] Headers follow hierarchy
- [ ] Lists are properly formatted
- [ ] Tables are properly formatted
- [ ] Code blocks specify language
- [ ] Inline code uses backticks
