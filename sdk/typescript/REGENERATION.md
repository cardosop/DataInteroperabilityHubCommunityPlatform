# TypeScript SDK — regeneration note

`api.ts` (and the rest of this package) is generated by OpenAPI
Generator from the backend's live OpenAPI document. Regeneration
requires a FULL backend (paid layer included):

1. Start the full stack (`docker compose -f docker-compose.test.yml up`).
2. `docker compose exec api-service python manage.py spectacular --file /tmp/openapi.yaml`
3. Run openapi-generator typescript-axios against that file.

Regeneration against a core-only backend would silently DROP the paid
API surface (semantic, marketplace, billing, baas, ml, ai, social) —
never do that. The checked-in `api.ts` always reflects the full API
(the public client for the hosted SaaS).
