# Security Policy

## Reporting a vulnerability

Please report security issues privately — do NOT open a public issue.

Email: **security@meshant.com** (PGP available on request).

Include: affected version, a description of the issue, steps to
reproduce (or a proof of concept), and any suggested mitigations.
You will receive an acknowledgement within 3 business days and a
status update within 14 days.

## Supported versions

| Version | Supported |
|---|---|
| latest release (vYYYY.MM.N tags) | Yes |
| older releases | No |

## Scope

This repository's core platform only. The hosted SaaS (semantic layer,
marketplace, billing) has its own disclosure program — see meshant.com.
